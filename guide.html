Teacher getting started

A quick tour of the librarian controls so you're ready to go in a few minutes.

1. Sign in as admin

Click Sign in in the top bar and use the admin account (admin / admin123 — change it in Admin → My Account). You'll land on the Admin Dashboard.

2. Add your books

Admin → Books → + Add book. Enter the title, author, and 13-digit ISBN. The site can auto-fill the cover, description, and a retail price. You can set a reading level (Lexile) for each book.

3. Add your students

Admin → Students. Use + Add student (one at a time) or Bulk add to paste a list — optionally Name | Class. Each student gets a class (7A/7B/8A/8B). Student passwords are encrypted but you can view them via the View button.

4. Create reading groups

Admin → Reading groups → + New reading group. Assign a book, pages to read, a due date, and pick the students. They'll see "Your book to get" on their My Library page.

5. Point students to the right pages

  • Home — announcements, featured picks, top rated.
  • Catalog — browse/search, check out, place holds, review books.
  • Checkout — the no-login kiosk for scanning books in/out.
  • My Library — their books, holds, reading log, clubs, and account.

Handy admin settings

  • Home Page — change the room number, set a Book of the Week.
  • Backup / restore — download a JSON backup of everything.
  • Kiosk — turn the checkout kiosk on/off and see its activity.
  • Reports — who has what, overdue, most popular — export to CSV.
  • Announcements — post notices that appear on the home page.
